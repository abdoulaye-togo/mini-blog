# Mini-Blog

## Description

Mini-Blog est une application web permettant de gérer des articles.

## Fonctionnalités

- Afficher les articles
- Ajouter un article
- Modifier un article
- Supprimer un article
- Confirmation avant suppression
- Stockage des données dans MySQL

## Technologies utilisées

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Installation

1. Installer XAMPP.
2. Démarrer Apache et MySQL.
3. Placer le projet dans le dossier `htdocs`.
4. Créer la base de données MySQL.
5. Configurer la connexion à la base de données dans `connexion.php`.
6. Ouvrir le projet dans un navigateur avec :

http://localhost/mini-blog/

## Utilisation

Depuis la page d'accueil, il est possible de :

- consulter les articles ;
- ajouter un article ;
- modifier un article ;
- supprimer un article.
